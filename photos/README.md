# Фото персон

Имя файла: `№_Фамилия ИО.jpg`, где № — номер персоны в GEDKeeper.
Примеры: `48_Третьяков АК.jpg`, `89_Третьяков Д.jpg`.

Перед загрузкой уменьшите фото через `tools/сборщик.html` (шаг 3): он сожмёт снимок до 1200 px и сам предложит правильное имя.
Фото людей, родившихся после 1925 года, сюда не кладите: этих людей на сайте нет, а сам файл всё равно будет виден всем.
