# Инструкция: сайт «Род Третьяковых» на GitHub

Схема работы:

| Что | Где ведётся | Как попадает на сайт |
|---|---|---|
| Люди и связи | **GEDKeeper** на вашем компьютере | `tools/сборщик.html` → файлы `persons.*`, `families.*` → папка `data` → GitHub Desktop |
| Фото | папка у вас на компьютере | `tools/сборщик.html` (уменьшить и назвать) → папка `photos` → GitHub Desktop |
| Исследование: источники, вехи, места, версии | ведёт Claude | Claude присылает архив с файлами `data/research.*`, `sources.*`, `places.*`, `milestones.js` → папка `data` → GitHub Desktop |
| Мелкая правка | сайт github.com | кнопка ✏️ прямо в браузере |

Содержание: А — первый запуск (один раз, около 30 минут). Б — обычная работа. В — если что-то не так.

---

## А. Первый запуск

### А1. Аккаунт GitHub и защита
1. Откройте https://github.com → **Sign up**. Введите e-mail, пароль и имя пользователя (латиницей, например `tretyakov-rod`). Имя войдёт в адрес сайта.
2. Подтвердите e-mail по письму.
3. Включите двухфакторную защиту: фото профиля (справа вверху) → **Settings** → **Password and authentication** → **Enable two-factor authentication**. Удобнее всего через приложение-аутентификатор на телефоне (Яндекс Ключ, Google Authenticator и т. п.).
   **Сохраните резервные коды восстановления** (Recovery codes) в надёжном месте.

> Публичный репозиторий **видят все, а изменять может только владелец** и те, кого вы сами добавите в Settings → Collaborators. Чужие предложения изменений (pull request) без вашего согласия не принимаются. Вся история хранится, любую версию можно вернуть.

### А2. Репозиторий (хранилище сайта)
Репозиторий уже создан: **https://github.com/punic09-hue/tree_TRETYAKOV** (публичный).
Адрес сайта после включения Pages (шаг А5): **https://punic09-hue.github.io/tree_TRETYAKOV/**

### А3. Программа GitHub Desktop
1. Скачайте с https://desktop.github.com и установите.
2. При первом запуске выберите **Sign in to GitHub.com** и войдите в свой аккаунт (откроется браузер, нажмите Authorize).
3. **File → Clone repository** → вкладка **GitHub.com** → выберите `tree_TRETYAKOV` → **Local path**, например `C:\Сайт\tree_TRETYAKOV` → **Clone**.
   На компьютере появится папка-копия сайта, пока пустая.

### А4. Первая загрузка файлов
1. Распакуйте архив от Claude (`Третьяковы_сайт_GitHub_….zip`). Внутри папка `сайт`.
2. Скопируйте **всё содержимое** папки `сайт` в `C:\Сайт\tree_TRETYAKOV`: `index.html`, `.nojekyll` и папки `assets`, `data`, `photos`, `tools`, а также `README.md` и эту инструкцию.
   Файл `.nojekyll` может быть невидим. Включите в проводнике Вид → Показать → Скрытые элементы и проверьте, что он скопировался.
3. Откройте `C:\Сайт\tree_TRETYAKOV\index.html` двойным щелчком: сайт должен открыться и без интернета. Это ваша проверка.
4. В GitHub Desktop слева появится список новых файлов. Внизу в поле **Summary** напишите, например, `Первая загрузка` → **Commit to main**.
5. Нажмите вверху **Publish branch** (или **Push origin**).

### А5. Включить сайт (GitHub Pages)
1. На github.com откройте репозиторий → **Settings** → слева **Pages**.
2. **Source**: *Deploy from a branch*. **Branch**: `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты вверху страницы Pages появится адрес вида `https://punic09-hue.github.io/tree_TRETYAKOV/`. Это и есть сайт, ссылкой можно делиться.

> **Карта.** Яндекс.Карты на сайте github.io могут попросить ключ. Если вкладка «Карта» не загрузится, получите бесплатный ключ JavaScript API в кабинете https://developer.tech.yandex.ru и пришлите его Claude: он впишет ключ в файл.

---

### А6. Разрешить Claude обновлять сайт (по желанию)
Чтобы Claude сам выкладывал обновления при каждом изменении, этот репозиторий нужно добавить в источники его сеанса: в приложении Claude откройте настройки текущей задачи (сеанса) → раздел источников / репозиториев GitHub → добавьте `punic09-hue/tree_TRETYAKOV`. При подключении GitHub попросит разрешить доступ только к выбранным репозиториям — выбирайте **только этот**.
Без этого Claude присылает архив, а загружаете вы через GitHub Desktop (раздел Б).

## Б. Обычная работа

### Б1. Изменили что-то в GEDKeeper
1. GEDKeeper → **Файл → Экспорт → GEDCOM** (.ged) → сохраните куда угодно, но **не в папку сайта**.
   В файле полная база, включая живущих, публиковать его нельзя.
2. Откройте `C:\Сайт\tree_TRETYAKOV\tools\сборщик.html` двойным щелчком.
3. Шаг 1 → **Выбрать файл .ged**. Сборщик покажет, сколько человек попадёт на сайт, сколько скрыто (родившиеся после 1925 года и их потомки) и сколько людей без года рождения.
   **Просмотрите людей без года рождения**: если среди них есть ныне живущие, впишите им год в GEDKeeper и повторите.
4. Шаг 2 → **Все четыре**. Скачаются `persons.js`, `persons.csv`, `families.js`, `families.csv`.
5. Перенесите их в `C:\Сайт\tree_TRETYAKOV\data\` с заменой.
6. Откройте `index.html` и проверьте.
7. GitHub Desktop → Summary: `Обновление из GEDKeeper` → **Commit to main** → **Push origin**. Через 1–2 минуты изменения появятся на сайте.

> Сведения исследования (метрики с шифрами ГАСО, дословные выписки, примечания, места на карте, ветви) привязаны к **№ персоны в GEDKeeper**. Поэтому **не меняйте номера** уже существующих людей, иначе эти сведения от них «отвалятся».

### Б2. Добавить или заменить фото
1. `tools/сборщик.html`: сначала шаг 1 (загрузите .ged, чтобы подставлялись имена), затем шаг 3 → **Выбрать фото** (можно несколько сразу).
2. У каждого фото проверьте № в GEDKeeper. Сборщик покажет имя файла, например `48_Третьяков АК.jpg` → **Сохранить**.
3. Положите файлы в `C:\Сайт\tree_TRETYAKOV\photos\`. Если фото с таким именем уже есть, оно заменится.
4. GitHub Desktop → Commit → Push.

Фото людей, родившихся после 1925 года, не загружайте: сам файл будет виден всем.
Удалить фото: удалите файл из папки `photos` → Commit → Push.

### Б3. Новые находки исследования
Присылайте Claude сканы, выписки и отчёты. Он пришлёт архив с обновлёнными `data/research.js` и `research.csv`, `sources.*`, `places.*`, `milestones.js`. Скопируйте их в `data` с заменой → Commit → Push.

### Б4. Мелкая правка без программ
github.com → репозиторий → файл (например, `data/milestones.js`) → карандаш ✏️ **Edit** → исправьте → **Commit changes**.

### Б5. Тот же сайт для другого рода
Скопируйте репозиторий (Use this template или просто новую папку). В `data/config.js` поменяйте название, `rootNum` (№ родоначальника) и `focusNum` (№ главного героя). Затем загрузите .ged другого рода через сборщик. Оформление менять не нужно.

## В. Если что-то не так

| Признак | Что сделать |
|---|---|
| Сайт не обновился | Подождите 2–3 минуты, обновите страницу с Ctrl+F5. На github.com → вкладка **Actions** должна быть зелёная галочка «pages build and deployment». |
| Вместо букв «кракозябры» | CSV открывали и сохраняли в Excel. Не сохраняйте `persons.csv` из Excel: сайт читает `.js`, а CSV нужен для просмотра. Пересоберите файлы сборщиком. |
| Пропали метрики или примечания у человека | В GEDKeeper сменился № персоны. Верните прежний № или сообщите Claude новый. |
| Фото не показывается | Имя файла должно точно совпадать: `№_Фамилия ИО.jpg`, буква «ё» как в GEDKeeper, расширение `.jpg` маленькими буквами. |
| Вернуть прежнюю версию | GitHub Desktop → **History** → правой кнопкой по нужной записи → **Revert changes in commit** → Push. |
| Удалить что-то навсегда (например, случайно загруженный .ged) | Удалите файл и сделайте Push, затем напишите Claude: из истории файл тоже нужно вычистить, иначе старые версии останутся видны. |

## Состав папки сайта
```
index.html            ← структура страницы (без данных)
.nojekyll             ← служебный файл для GitHub Pages
assets/               ← оформление и движок (core.js, tree.css, hero-art.js)
data/                 ← данные: *.js читает сайт, *.csv — копия для просмотра в Excel
   config.js          ← название, родоначальник, контакт, граница 1925
   persons.* families.*   ← из GEDKeeper (через сборщик)
   research.* sources.* places.* milestones.js  ← исследование (ведёт Claude)
photos/               ← фото: №_Фамилия ИО.jpg
tools/сборщик.html    ← работает только на вашем компьютере
```
