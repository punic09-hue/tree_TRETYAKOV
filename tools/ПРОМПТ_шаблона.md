# Промпт: сайт родословия для нового рода на основе шаблона

Скопируйте этот текст в новый чат вместе с архивом шаблона и материалами нового рода (файл .ged из GEDKeeper, таблицы, выписки).

---

Ты помогаешь сделать сайт родословия рода **[ФАМИЛИЯ]** ([место]). Основа — архив «Шаблон_сайта_родословия_…zip»: в папке `сайт/` готовый статический сайт (GitHub Pages, без сборки и без ключей API). Код и оформление не переделывай без моей просьбы: меняются только данные в `сайт/data/` и фото в `сайт/photos/`.

## Что в шаблоне
- `index.html`, `assets/` (core.js — дерево, карточки, поиск; tree.css; hero-art.js — рисунок обложки; leaflet/ — карта). Разделы: Главная (вехи по поколениям), Дерево, Люди, Источники, Карта (подложка Яндекс по умолчанию, переключатель на Google), Исследование (плитки разделов).
- Темы светлая и тёмно-синяя. Без горизонтальной прокрутки на 390/393/1366 px — проверять после каждого изменения.
- `tools/сборщик.html` — открыть локально, загрузить .ged из GEDKeeper, получить `persons.js`/`families.js`.
- `tools/make_studies.py <папка csv>` и `tools/make_places_info.py <csv мест>` — сборка данных исследования и карты из csv (формат листов как в проекте-образце; при другом формате поправь скрипты).
- `tools/make_template.py` — пересобирает этот шаблон.

## Файлы данных (`сайт/data/`) — в шаблоне демонстрационные, заменить
- `config.js` — название, подзаголовок, контакт, `short` (в шапке), `kicker`/`heading` (обложка), `heroArt`, `levels` (подписи уровней вех: viz — местный завод/село, ekb — город, ru, world), `mapCenter`/`mapZoom`, `updated`, `cutoff` (год рождения, после которого люди не публикуются), `rootNum`/`focusNum` (№ из GEDKeeper).
- `persons.js` — `TREE_PERSONS`: id, num (№ GEDKeeper), name, sex (М/Ж), gen (римское поколение), branch, b, d, father, mother, spouses[], pri (прямая линия), ev[] (метрики: kind, date, res, fam, code, no, note), places[] (id мест), прочие поля можно оставлять пустыми.
- `families.js` — `TREE_FAMILIES`: id, gen, branch, h, w, date, note.
- `sources.js` — `TREE_SOURCES`: n, res (ПОЛОЖИТЕЛЬНЫЙ/ОТРИЦАТЕЛЬНЫЙ/…), type, ref, yr, what, got, where, date.
- `research.js` — `TREE_RESEARCH`: по № персоны — заметки исследователя.
- `milestones.js` — вехи по поколениям прямой линии: who, ids (№), years, intro, ev[{y, l: viz|ekb|ru|world, t, u}].
- `places.js` — `TREE_PLACES`: id, name, addr, lat, lon (пусто — точка ищется геокодером по `geo`), exact, cat, period, about, events[{d, t, w, ids, hid}], geo, coord.
- `studies.js` — `TREE_STUDIES`: разделы «Исследования» {ключ: {ico, title, cols, rows}}; у раздела `maps` справа от текста — превью по ссылке.

## Правила
1. Координаты не выдумывать: только сверенные по источнику, иначе пусто + строка `geo` (сайт пометит точку как примерную).
2. Люди, родившиеся после `cutoff`, на сайте не публикуются; в событиях на карте — без имён.
3. После каждого изменения проводить его по всем связанным файлам и выдавать архив.
4. Публикация: репозиторий GitHub, Pages из ветки main, корень. Пушить только с моего подтверждения.
5. Рисунок обложки (`heroArt`) — свой для рода: добавь вариант в `assets/hero-art.js` по образцу `dam`.
