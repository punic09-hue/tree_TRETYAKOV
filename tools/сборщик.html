🔧 Сборщик данных сайта

Этот файл работает только у вас на компьютере: выбранные файлы никуда не отправляются. Он превращает выгрузку из GEDKeeper в файлы для сайта и сразу убирает людей, родившихся после 1925 года — полная база в интернет не попадает.

1. Выгрузка из GEDKeeper (.ged)

GEDKeeper → Файл → Экспорт → GEDCOM. Выберите получившийся файл.

2. Сохранить файлы для сайта

Положите их в папку data вашей копии сайта (с заменой), затем в GitHub Desktop нажмите Commit и Push.

Если браузер спросит, разрешите скачивание нескольких файлов.

3. Подготовить фото

Выберите фото — сборщик уменьшит их до 1200 px (JPEG, ≈200–400 КБ) и предложит правильное имя по № из GEDKeeper. Оригиналы храните у себя.
